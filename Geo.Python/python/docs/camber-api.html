camber API

Public Python surface. Points are tuples or vec2/vec3. Solids: + union, − cut, & intersect. max_deviation=-1 uses the Part default. There is no Solid | operator.

Core

class

Part(low: Point3Like, high: Point3Like, tolerance: float=0.01) -> None

CAD session: operating box, sketches, solids, booleans, import/export.

Booleans

  • Part.batch_boolean_chain(mesh_a: Solid, steps: Sequence[tuple[Solid, int]]) -> Solid Apply ``steps`` as ``[(solid, BOOLEAN_*), ...]`` in order onto ``mesh_a``.
  • Part.batch_subtract(base: Solid, cutters: Iterable[Solid], name: EntityName | None=None) -> Solid Subtract the union of ``cutters`` from ``base`` in one Boolean step.
  • Part.batch_union(meshes: Iterable[Solid], name: EntityName | None=None) -> Solid | None Union many solids. Empty list → None; one item returned as-is.
  • Part.boolean(a: Solid, b: Solid, operation: int, name: EntityName | None=None) -> Solid CSG: ``operation`` is BOOLEAN_UNION / SUBTRACT / INTERSECT.
  • Part.intersect(a: Solid, b: Solid, name: EntityName | None=None) -> Solid Boolean intersection. Same as ``a & b``.
  • Part.subtract(a: Solid, b: Solid, name: EntityName | None=None) -> Solid Boolean subtraction ``a minus b``. Same as ``a - b``.
  • Part.union(a: Solid, b: Solid, name: EntityName | None=None) -> Solid Boolean union. Same as ``a + b``.

Create

  • Part.assembly(name: EntityName | None=None) -> Assembly Create or get an Assembly attached to this part.
  • Part.copy_solid(source: Solid, name: EntityName) -> Solid Deep-copy a solid, rewriting its entity prefixes to the required new name.
  • Part.section_sketch(solid: Solid, plane: Frame | None=None, name: EntityName | None=None) -> Sketch Return the cross-section of ``solid`` as sampled curves in a Sketch.
  • Part.sketch(plane: str='xy', name: EntityName | None=None, origin_name: EntityName | None=None, frame: Frame | None=None, constrained: bool=False) -> Sketch 2D sketch. ``plane`` is ``xy``/``xz``/``yz``; or pass ``frame=``.

Import

  • Part.load_obj(path: str, group_border_angle_deg: float=-1, name: EntityName | None=None, scale: float=1.0) -> Surface | Solid Import Wavefront OBJ. ``group_border_angle_deg`` splits patches at sharp edges (viewer edges are drawn on patch borders; use e.g. 22 when the OBJ has no ``g`` tags). ``scale`` multiplies vertex positions (e.g. 0.01 for cm→m).
  • Part.load_off(path: str, group_border_angle_deg: float, name: EntityName | None=None, require_watertight: bool=True) -> Surface | Solid Import OFF as a Solid or, when allowed, an open Surface.
  • Part.load_stl(path: str, group_border_angle_deg: float, name: EntityName | None=None, require_watertight: bool=True) -> Surface | Solid Import STL as a Solid or, when allowed, an open Surface.
  • Part.solid_from_mesh(positions: Sequence[Point3Like], triangles: Sequence[Sequence[int]], name: EntityName | None=None) -> Surface | Solid Build a Solid or open Surface from world-space vertices and triangles.

Inspect

  • Part.solid(name: EntityName) -> Surface | Solid | None Look up a Solid or Surface already registered on this part, or None.

Multi-profile

  • Part.loft(sketches: Sequence[Sketch], options: LoftOptions | None=None, name: EntityName | None=None, max_deviation: float=-1, *, first_curves: Sequence[str] | None=None) -> Solid Loft through Sketches, preserving their authored start points as connectors.
  • Part.loft_surface(sections: Sequence[Sketch], *, guides: Sequence[Curve3D] | None=None, start_tangent: Point3Like | None=None, end_tangent: Point3Like | None=None, name: EntityName | None=None, max_deviation: float=-1) -> Surface Create an uncapped NURBS sheet through sketch sections.

Primitives

  • Part.cube(pose: Frame | Point3Like, extent: float, name: EntityName | None=None) -> Solid Axis-aligned cube of side ``extent`` in the pose (center at origin).
  • Part.cuboid(pose_or_min: Frame | Point3Like, extents_or_max: Point3Like, name: EntityName | None=None) -> Solid Pose + local extents, or world AABB min/max.
  • Part.cylinder(origin: Point3Like, radius: float, height: float, name: EntityName | None=None, axis: Literal['x', 'y', 'z']='z', max_deviation: float=-1) -> Solid Cylinder from a point or Frame. ``axis`` is ``x``/``y``/``z`` if origin is a point.
  • Part.cylinder_revolve(pose: Frame, radius: float, height: float, name: EntityName | None=None, max_deviation: float=-1) -> Solid Cylinder as a revolve of a rectangle (same pose convention as cylinder).
  • Part.sphere(center: Point3Like, radius: float, name: EntityName | None=None, max_deviation: float=-1) -> Solid Sphere at ``center`` (point or Frame).

Surface modeling

  • Part.sew(surfaces: Iterable[Surface], *, make_solid: bool=False, name: EntityName | None=None) -> Surface | Solid Sew exactly coincident surface boundaries.

Other

  • Part.add_line(start: Point3Like | EntityName, end: Point3Like | EntityName, name: EntityName | None=None) -> Curve3D 3D construction line from coordinates, named points, or one of each.
  • Part.add_plane(plane_name: EntityName, origin_anchor_name: EntityName) -> None Named construction plane at a named origin point.
  • Part.create_metric_thread_for_bolt_negative(pose: Frame, major_diameter: float, pitch: float, length: float, name: EntityName | None=None, max_deviation: float=-1, right_handed: bool=True, outer_radius: float=-1) -> Solid ISO 60° external-thread cutter (subtract from a shank). Axis is pose.z.
  • Part.create_metric_thread_for_hole_negative(pose: Frame, major_diameter: float, pitch: float, length: float, name: EntityName | None=None, max_deviation: float=-1, right_handed: bool=True, include_bore_chamfers: bool=False) -> Solid ISO 60° internal-thread cutter (subtract from a holed plate). Axis is pose.z.
  • Part.create_metric_thread_for_nut_negative(pose: Frame, major_diameter: float, pitch: float, length: float, name: EntityName | None=None, max_deviation: float=-1, right_handed: bool=True, include_bore_chamfers: bool=True) -> Solid ISO 60° internal-thread cutter (subtract from a nut). Axis is pose.z.
  • Part.plane_frame(plane: str) -> Frame | None Frame of a named part plane, or None.
  • Part.show(title: str='Camber') -> None Open the 3D viewer on all meshes in this part.
  • Part.sketch_interactive(plane: str='xy', name: EntityName | None=None, part_var: str='part', sketch_var: str='sk', frame: Frame | None=None, emit_frame: bool=False) -> tuple[Sketch | None, str | None] Draw a sketch in the viewer. Finish copies camber Python to the clipboard.
  • Part.smallest_unit() -> float Lattice step: operating-box extent / slices (~1e-6 of the box).

Properties

  • Part.curve_names Canonical renderer mesh-edge curve names across all solids in this Part.
  • Part.max_deviation Default tessellation tolerance (world units).
  • Part.name Part instance name.
  • Part.operations Successful solid-producing features in chronological order.
  • Part.patch_names Canonical renderer patch names across all solids in this Part.
  • Part.point_names Canonical renderer edge-anchor names across all solids in this Part.

Sketch # Part.sketch / Part.sketch(..., constrained=True)

2D sketch on a Part: plotter strips, named curves, and optional constraints.

Build solids

  • Sketch.extrude_along_curve(curve: Curve3D, name: EntityName | None=None, max_deviation: float=-1, twist: float=0, reference_direction: Point3Like | None=None) -> Solid Sweep this profile along a 3D curve.
  • Sketch.extrude_along_curve_strip(curves: Sequence[Curve3D], name: EntityName | None=None, max_deviation: float=-1, twist: float=0, reference_direction: Point3Like | None=None) -> Solid Sweep a profile along connected curves; sharp joins use a miter section.
  • Sketch.extrude_along_sketch(guide: Sketch, name: EntityName | None=None, max_deviation: float=-1) -> Solid Sweep this profile along a guide sketch.
  • Sketch.extrude_two_sides(plus_z: float, minus_z: float=0.0, name: EntityName | None=None, max_deviation: float=-1, twist: float=0) -> Solid Extrude along both sides of the sketch plane.
  • Sketch.extrude_until_face(target: Solid, patch_name: EntityName, name: EntityName | None=None, max_deviation: float=-1) -> Solid Extrude to a named face of a target solid.
  • Sketch.extrude_until_next(target: Solid, name: EntityName | None=None, max_deviation: float=-1) -> Solid Extrude to the first intersection with a target solid.
  • Sketch.extrude_until_surface(surface: Surface, name: EntityName | None=None, max_deviation: float=-1) -> Solid Extrude to an open surface spanning the entire profile.
  • Sketch.revolve(angle: float, name: EntityName | None=None, max_deviation: float=-1) -> Solid Revolve this sketch around its X axis by an angle in radians.

Project

  • Sketch.project_onto(solid: Solid, name: EntityName | None=None, max_deviation: float=-1) -> ProjectedSketch Project this sketch onto a solid along its plane normal.

Surface modeling

Closed triangle volume owned by a Part.

  • Solid.countersink_hole(mouth: Frame, diameter: float, countersink_diameter: float, included_angle: float, depth: float | None=None, *, name: EntityName | None=None, max_deviation: float=-1) -> Solid Drill a hole with a conical countersink; angle is in radians.

Inspect

Transforms

  • Solid.mirror(plane: Frame | None=None, name: EntityName | None=None) -> Solid Return a reflected copy across a Frame's XY plane.
  • Solid.pattern_circular(count: int, axis: Curve3D | tuple[Point3Like, Point3Like] | None=None, angle: float=6.283185307179586, name: EntityName | None=None) -> list[Solid] Return copies rotated around an axis, including this seed.
  • Solid.pattern_linear(count: int, step: Point3Like, name: EntityName | None=None) -> list[Solid] Return independent copies at equal XYZ steps, including this seed.

Operators

  • Solid & Solid Boolean intersection. Result keeps this solid's name.
  • Solid - Solid Boolean subtraction (this minus other). Result keeps this solid's name.

Other

  • Solid.located(location: Point3Like) -> Solid Return this solid translated to a world-space location.
  • Solid.mesh() -> tuple[list[vec3], list[tuple[int, int, int]]] Raw kernel triangles: ``(points, triangles)`` as ``vec3`` and ``(i, j, k)``.
  • Solid.patch_frame_at(index: int) -> Frame Area-centroid frame of a tessellated patch (normal from its winding).
  • Solid.save_iges(path: str) -> None Write IGES (faceted).
  • Solid.save_obj(path: str) -> None Write Wavefront OBJ.
  • Solid.save_off(path: str) -> None Write OFF mesh.
  • Solid.save_step(path: str) -> None Write STEP (faceted).
  • Solid.save_stl(path: str, binary: bool=True) -> None Write STL. ``binary=False`` is ASCII.

  • Solid.trim(surface: Surface, *, side: Literal['normal', 'opposite']='normal', name: EntityName | None=None) -> Solid Trim this closed solid by an open Surface.
  • Solid.volume() -> float Absolute volume of this closed solid.

Properties

  • Solid.curve_names Canonical mesh-edge curve names, accepted by fillet and chamfer.
  • Solid.is_volume True if the kernel treats this mesh as a closed volume.
  • Solid.name Kernel mesh name.
  • Solid.patch_names Canonical patch names, identical to the renderer's face names.
  • Solid.point_names Canonical displayed edge-anchor names (start, midpoint, end, and closed-loop quarters).
  • Solid.triangle_count Number of triangles in the kernel mesh.
