camber API

Public Python surface. Points are tuples or vec2/vec3. Solids: + union, − cut, & intersect. max_deviation=-1 uses the Part default. There is no Solid | operator.

Core

class

Part(low, high, tolerance=0.01)

CAD session: operating box, sketches, solids, booleans, import/export.

  • Part.max_deviation Default tessellation tolerance (world units).
  • Part.name Part instance name.
  • Part.add_line(start, end, name=None) 3D construction line (not a sketch). Returns Curve.
  • Part.add_line_by_names(start_name, end_name, name=None) 3D line between two named points already on the part.
  • Part.add_plane(plane_name, origin_anchor_name) Named construction plane at a named origin point.
  • Part.assembly(name=None) Create or get an Assembly attached to this part.
  • Part.batch_boolean_chain(mesh_a, steps) Apply ``steps`` as ``[(solid, BOOLEAN_*), ...]`` in order onto ``mesh_a``.
  • Part.batch_union(meshes) Union many solids. Empty list → None; one item returned as-is.
  • Part.boolean(a, b, operation, name=None) CSG: ``operation`` is BOOLEAN_UNION / DIFFERENCE / INTERSECT.
  • Part.chamfer(solid, edges, distance, name=None, max_deviation=-1) Chamfer named edges. ``edges`` is a string or list of names.
  • Part.copy_solid(source, name) Deep-copy a solid. `name` is required and must differ from the source; all entity prefixes are rewritten.
  • Part.create_metric_thread_for_bolt_negative(pose, major_diameter, pitch, length, name=None, max_deviation=-1, right_handed=True, outer_radius=-1) ISO 60° external-thread cutter (subtract from a shank). Axis is pose.z.
  • Part.create_metric_thread_for_hole_negative(pose, major_diameter, pitch, length, name=None, max_deviation=-1, right_handed=True, include_bore_chamfers=False) ISO 60° internal-thread cutter (subtract from a holed plate). Axis is pose.z.
  • Part.create_metric_thread_for_nut_negative(pose, major_diameter, pitch, length, name=None, max_deviation=-1, right_handed=True, include_bore_chamfers=True) ISO 60° internal-thread cutter (subtract from a nut). Axis is pose.z.
  • Part.cube(pose, extent, name=None) Axis-aligned cube of side ``extent`` in the pose (center at origin).
  • Part.cuboid(pose_or_min, extents_or_max, name=None) Pose + local extents, or world AABB min/max.
  • Part.cut(a, b, name=None) Boolean difference ``a minus b``. Same as ``a - b``.
  • Part.cylinder(origin, radius, height, name=None, axis='z', max_deviation=-1) Cylinder from a point or Frame. ``axis`` is ``x``/``y``/``z`` if origin is a point.
  • Part.cylinder_revolve(pose, radius, height, name=None, max_deviation=-1) Cylinder as a revolve of a rectangle (same pose convention as cylinder).
  • Part.extrude(sketch, height, name=None, both_sides=False, max_deviation=-1, twist=0) Extrude along the sketch-plane normal. ``height`` world units; ``twist`` rad per unit length.
  • Part.extrude_along_curve(sketch, curve, name=None, max_deviation=-1, twist=0) Sweep the sketch along a 3D Curve.
  • Part.extrude_along_curve_strip(sketch, curves, name=None, max_deviation=-1, twist=0) Sweep the sketch along a sequence of Curves (G1 strip).
  • Part.extrude_along_sketch(profile, guide, name=None, max_deviation=-1) Sweep ``profile`` along a 3D path taken from ``guide`` sketch curves.
  • Part.extrude_projected(projected, height, name=None) Extrude a ProjectedSketch along stored surface normals (negative = into solid).
  • Part.extrude_two_sides(sketch, plus_z, minus_z=0.0, name=None, max_deviation=-1, twist=0) Extrude ``plus_z`` along +normal and ``minus_z`` along −normal.
  • Part.fillet(solid, edges, radius, name=None, max_deviation=-1) Fillet named edges. ``edges`` is a string or list of names (joined with ``|``).
  • Part.intersect(a, b, name=None) Boolean intersection. Same as ``a & b``.
  • Part.load_obj(path, group_border_angle_deg=-1, name=None) Import Wavefront OBJ.
  • Part.load_off(path, group_border_angle_deg, name=None, require_watertight=True) Import OFF mesh.
  • Part.load_stl(path, group_border_angle_deg, name=None, require_watertight=True) Import STL. ``group_border_angle_deg`` splits patches at sharp edges.
  • Part.loft(sketches, options=None, name=None, max_deviation=-1) Loft through a sequence of Sketches. ``options`` is LoftOptions.
  • Part.plane_frame(plane) Frame of a named part plane, or None.
  • Part.project_sketch(sketch, solid, name=None, max_deviation=-1) Tessellate sketch and project onto solid along the sketch-plane normal.
  • Part.raycast(solid, origin, direction) Nearest mesh hit along ``origin`` + t * ``direction``, or ``None``.
  • Part.revolve(sketch, angle, name=None, max_deviation=-1) Revolve the sketch about sketch X by ``angle`` radians.
  • Part.show(title='Camber') Open the 3D viewer on all meshes in this part.
  • Part.sketch(plane='xy', name=None, origin_name=None, frame=None, constrained=False) 2D sketch. ``plane`` is ``xy``/``xz``/``yz``; or pass ``frame=``.
  • Part.sketch_interactive(plane='xy', name=None, part_var='part', sketch_var='sk', frame=None, emit_frame=False) Draw a sketch in the viewer. Finish copies camber Python to the clipboard.
  • Part.smallest_unit() Lattice step: operating-box extent / slices (~1e-6 of the box).
  • Part.solid(name) Look up a Solid already registered on this part by name, or None.
  • Part.solid_from_mesh(positions, triangles, name=None) Build a solid from world-space vertices and ``(i, j, k)`` triangles.
  • Part.sphere(center, radius, name=None, max_deviation=-1) Sphere at ``center`` (point or Frame).
  • Part.union(a, b, name=None) Boolean union. Same as ``a + b``.
class

Sketch # Part.sketch / Part.sketch(..., constrained=True)

2D sketch on a Part: plotter strips, named curves, and optional constraints.

  • Sketch.constraint_count Number of constraints, or -1 if this is a plotter-only sketch.
  • Sketch.curve_count Number of constraint-solver curves, or -1 if this is a plotter-only sketch.
  • Sketch.frame World Frame of this sketch plane.
  • Sketch.name Kernel sketch name.
  • Sketch.solve_after_every_constraint If True, the kernel solves after each constraint (default).
  • Sketch.add_arc(start, mid, end, name=None, construction=False) Circular arc through three points. Returns SketchCurve.
  • Sketch.add_circle(center, radius, name=None, construction=False) Circle. ``center`` is XY or a named point. Returns SketchCurve.
  • Sketch.add_line(start, end, name=None, construction=False) Segment from start to end (XY or named points). Returns SketchCurve.
  • Sketch.add_naca4(code, leading_edge, chord_length, chord_angle=0.0, samples_per_side=36, analytic_end_tangents=True, te_trim=0.01) Closed NACA 4-digit airfoil. ``code`` is ``2412`` or the integer 2412.
  • Sketch.add_rectangle(corner_a, corner_b, names=None) Axis-aligned rectangle, CCW from the lower-left corner.
  • Sketch.add_rectangle_centered(center, size_x, size_y, names=None) Axis-aligned rectangle. `names` is (south, east, north, west) for the four sides.
  • Sketch.add_spline(points, start_tangent=None, end_tangent=None, name=None) Cubic Hermite spline through 2D points.
  • Sketch.add_text(text, origin, family='Arial', em_size=0.2, bold=False, italic=False) Add TrueType glyph outlines at the baseline origin (sketch XY).
  • Sketch.angle(curve_a, curve_b, degrees) Angle between two lines, in degrees. Returns self.
  • Sketch.append_arc_left(radius, angle=None) Tangential left turn of ``angle`` radians (default π/2) at ``radius``.
  • Sketch.append_arc_right(radius, angle=None) Tangential right turn of ``angle`` radians (default π/2) at ``radius``.
  • Sketch.append_line(end) Plotter: line from the current pen to ``end``. Returns self.
  • Sketch.append_line_horizontal(end_x) Plotter: horizontal line to sketch X = ``end_x``. Returns self.
  • Sketch.append_line_vertical(end_y) Plotter: vertical line to sketch Y = ``end_y``. Returns self.
  • Sketch.append_spline(points, start_tangent=None, end_tangent=None) Hermite spline from the current strip end through ``points``.
  • Sketch.coincident(point_a, point_b) Coincident two points. Each is a name ("Line1@1.000") or ("xy", x, y).
  • Sketch.coincident_on_curve(point, curve, uniform) Place a named point on another curve at uniform parameter u in [0, 1].
  • Sketch.concentric(curve_a, curve_b) Share a center (circles/arcs). Returns self.
  • Sketch.distance(point_a, point_b, value) Distance between two points. Each is a name or ("xy", x, y).
  • Sketch.distance_to_line(point, line_curve, value) Perpendicular distance from a named point to a line.
  • Sketch.equal(curve_a, curve_b) Equal length (lines) or equal radius (circles/arcs). Returns self.
  • Sketch.eval_xy(point) Sketch-plane XY of a named point (``line @ 1.000``, ``sk @ "origin"``).
  • Sketch.fix(point) Pin a named point in the sketch plane. XY constants are ignored.
  • Sketch.horizontal(curve) Keep a line parallel to sketch X. Returns self.
  • Sketch.horizontal_distance(point_a, point_b, value) Signed horizontal offset ``b.x - a.x = value``.
  • Sketch.length(curve, value) Set line length. Returns self.
  • Sketch.midpoint(point, line_curve) Named point at the midpoint of a line. Returns self.
  • Sketch.move_to(point) Start a new disconnected strip at ``point``.
  • Sketch.offset(curves, distance, side='both', join='miter', end_cap='square', open_mode=None) Offset curves. Closed loops without forks use ``side='out'`` / ``'in'``.
  • Sketch.parallel(curve_a, curve_b) Keep two lines parallel. Returns self.
  • Sketch.perpendicular(curve_a, curve_b) Keep two lines perpendicular. Returns self.
  • Sketch.point_on_circle(point, circle_curve) Put a named point on a circle circumference.
  • Sketch.point_on_line(point, line_curve) Put a named point on a line (infinite line through the segment).
  • Sketch.polylines(max_deviation=-1) Tessellated sketch strips as a list of ``vec2`` polylines.
  • Sketch.radius(curve, value) Set circle/arc radius. Returns self.
  • Sketch.remove_last_constraint() Undo the last constraint. Returns self.
  • Sketch.remove_last_curve() Undo the last constraint-solver curve. Returns self.
  • Sketch.repeat_circular(curves, center, count, total_angle=None, include_original=False) Rotational copies about ``center``. Skips the 0° instance unless ``include_original``.
  • Sketch.repeat_grid(curves, count_x, count_y, step_x, step_y, include_original=False) Grid copies. Skips the (0, 0) cell unless ``include_original``.
  • Sketch.set_construction(curve, construction=True) Mark a sketch curve as construction geometry (excluded from extrude/loft).
  • Sketch.set_start(point) Set the strip pen without drawing (plotter ``Append*`` methods).
  • Sketch.show(title='Camber') Open the sketch viewer on this sketch's plane (default planes: xy, yz, zx).
  • Sketch.solve() Run the constraint solver. Returns self.
  • Sketch.tangent(line_curve, circular_curve) Line tangent to a circle/arc. Returns self.
  • Sketch.tangent_circles(curve_a, curve_b) Two circles/arcs tangent to each other. Returns self.
  • Sketch.triangulate(max_deviation=-1, working_volume=None, slices=None) Fill closed sketch contours. Nested holes and islands are handled by the kernel polygon tree.
  • Sketch.vertical(curve) Keep a line parallel to sketch Y. Returns self.
  • Sketch.vertical_distance(point_a, point_b, value) Signed vertical offset ``b.y - a.y = value``.
class

SketchCurve # Sketch.add_line / add_circle / add_arc

Named 2D curve from add_line / add_circle / add_arc. `curve @ 1.000` is "name@1.000".

class

Solid # Part.extrude / union / cut / …

Triangle mesh owned by a Part. Operators: ``+`` union, ``-`` cut, ``&`` intersect.

  • Solid + Solid Boolean union. Result keeps this solid's name.
  • Solid & Solid Boolean intersection. Result keeps this solid's name.
  • Solid - Solid Boolean difference (this minus other). Result keeps this solid's name.
  • Solid.is_volume True if the kernel treats this mesh as a closed volume.
  • Solid.name Kernel solid name (also used as the default boolean result name).
  • Solid.triangle_count Number of triangles in the kernel mesh.
  • Solid.is_watertight() True if every edge is shared by exactly two triangles.
  • Solid.mesh() Raw kernel triangles: ``(points, triangles)`` as ``vec3`` and ``(i, j, k)``.
  • Solid.save_iges(path) Write IGES (faceted).
  • Solid.save_obj(path) Write Wavefront OBJ.
  • Solid.save_off(path) Write OFF mesh.
  • Solid.save_step(path) Write STEP (faceted).
  • Solid.save_stl(path, binary=True) Write STL. ``binary=False`` is ASCII.
  • Solid.show(title='Camber') Open the 3D viewer on this solid.
  • Solid.signed_volume() Signed tetrahedron volume. Negative means inward orientation.
  • Solid.volume() Absolute volume of a watertight mesh.
class

ProjectedSketch # Part.project_sketch

Result of Part.project_sketch: named 3D polylines on a mesh with surface normals.

  • ProjectedSketch.curve_count Number of projected 3D polylines.
  • ProjectedSketch.name Kernel name of the projected sketch.
  • ProjectedSketch.curve_name_at(index) Name of the polyline at ``index``.

Pose

class

Frame(origin=None, x=None, y=None, z=None)

World pose: origin + right-handed orthonormal axes (GeoAPI CoordinateSystem).

  • Frame.from_plane(origin, normal, x, y) Same pose as Curves.Plane3D(origin, normal, x, y).GetCoordinateSystem().
  • Frame.offset(delta) Translate origin by ``delta`` (vec3 or 3-tuple). Axes unchanged.
  • Frame.to_global(local) Map a frame given in this local space into world. Returns a Frame.
  • Frame.to_local(other) Express ``other`` in this frame. Returns a Frame.
class

Curve # Curve.line / helix / circle / arc / spiral

3D guide curve (Line3D / Helix3D / Circle3D / Arc3D / Spiral3D).

  • Curve.name Kernel entity name.
  • Curve.arc(origin, x_axis, y_axis, radius, start_angle, sweep_angle, name=None) Circular arc. Angles in radians, from ``x_axis`` toward ``y_axis``.
  • Curve.circle(origin, x_axis, y_axis, radius, name=None) Full circle in the x/y plane of the given axes.
  • Curve.helix(origin, x_axis, y_axis, radius, pitch, turns, right_handed=True, name=None) Helix in the plane of ``x_axis``/``y_axis``; axis is their cross. ``pitch`` is z per turn.
  • Curve.line(start, end, name=None) World-space line from ``start`` to ``end`` (vec3 or 3-tuple).
  • Curve.spiral(origin, x_axis, y_axis, start_radius, end_radius, z_per_turn, turns, right_handed=True, name=None) Planar spiral with optional z advance (``z_per_turn``). Radii in the x/y plane.
class

LoftOptions(native=None)

GeoAPI LoftOptions. Enum fields are ints (see LOFT_STYLE_*).

  • LoftOptions.propeller_blade() Preset loft options for a propeller blade (smooth + robust caps).

Assembly

Assembly # Part.assembly

Rigid-part assembly solved by C# Geo Assembly constraints.

  • Assembly.name Assembly instance name.
  • Assembly.solve_after_every_constraint If True, the kernel solves after each constraint.
  • Assembly.add_part(solid, position=(0, 0, 0), orientation=(0, 0, 0, 1)) Place ``solid`` at ``position`` with quaternion ``orientation`` (x,y,z,w). Returns AssemblyPart.
  • Assembly.angle(a, b, radians) Angle between two axis datums, in radians.
  • Assembly.coincident(a, b, opposite_normals=None) Coincide two matching datums (point/point, axis/axis, plane/plane).
  • Assembly.concentric(a, b) Concentric axes/cylinders (two datums).
  • Assembly.distance(a, b, value) Distance between two point datums.
  • Assembly.fix(part) Lock an AssemblyPart in world (ground).
  • Assembly.parallel(a, b) Keep two axis datums parallel.
  • Assembly.perpendicular(a, b) Keep two axis datums perpendicular.
  • Assembly.plane_frame(reference) World Frame of a named assembly plane, or None.
  • Assembly.show(title='Camber') Open the 3D viewer on this assembly.
  • Assembly.solve() Run the assembly constraint solver. Returns a status string (may print it).

Vectors

class

vec2(x, y=None)

2D vector ``(x, y)``. Accepts ``vec2(x, y)``, ``vec2((x, y))``, or another vec2.

  • vec2 + vec2 Component-wise add. Tuples work.
  • vec2 * vec2 Scalar or component-wise multiply.
  • -vec2 Negate both components.
  • vec2 - vec2 Component-wise subtract.
  • vec2.copy() Return a new vec2 with the same components.
  • vec2.dot(other) Dot product with a vec2 or 2-tuple.
  • vec2.norm() Euclidean length.
  • vec2.tolist() Return ``[x, y]``.
class

vec3(x, y=None, z=None)

3D vector ``(x, y, z)``. ``vec3(s)`` fills all axes; tuples and vec3 copy.

  • vec3 + vec3 Component-wise add. Tuples work.
  • vec3 * vec3 Scalar or component-wise multiply.
  • -vec3 Negate all components.
  • vec3 - vec3 Component-wise subtract.
  • vec3 / vec3 Divide by a scalar.
  • vec3.copy() Return a new vec3 with the same components.
  • vec3.cross(other) Right-handed cross product. Returns vec3.
  • vec3.dot(other) Dot product with a vec3 or 3-tuple.
  • vec3.norm() Euclidean length.
  • vec3.normalized() Unit vector, or (0,0,0) if length is 0.
  • vec3.tolist() Return ``[x, y, z]``.

RayHit # Part.raycast

Nearest hit from ``Part.raycast``. ``t`` is 0 at the origin and 1 at the far end of the cast segment used by the kernel.

function

Fill polygons. Nested holes and islands are classified by a polygon tree.

function

Shoelace area on the working-volume lattice, converted back to world units. Positive is CCW. Pass the same ``working_volume`` as ``triangulate`` when comparing.

function

is_ccw(loop, working_volume=None, slices=None)

True if ``signed_area(loop)`` is positive (CCW in sketch XY).

function

point_in_polygon(loop, point, on_edge=True, working_volume=None, slices=None)

True if ``point`` is inside ``loop``. Boundary counts as inside unless ``on_edge=False``.

function

convex_hull(points, working_volume=None, slices=None)

2D convex hull as a CCW list of ``vec2`` (no closing duplicate).

function

tessellate_bezier(controls, max_deviation=0.01)

Adaptive polyline for a 2D Bezier given control points.

function

text_outlines(text, origin=(0, 0), family='Arial', em_size=0.2, bold=False, italic=False)

Tessellated glyph contours as a list of loops (``vec2``).

CadQuery compat

class

cqcompat.Workplane(inPlane='XY', origin=None, obj=None, part=None, size=1000.0, tolerance=0.01)

CadQuery-shaped modelling context backed by one shared camber ``Part``.

  • Workplane + Workplane Same as ``union``.
  • Workplane & Workplane Same as ``intersect``.
  • Workplane - Workplane Same as ``cut``.
  • Workplane.box(length, width, height, centered=True, combine=True, clean=True) Cuboid along the current workplane. ``clean`` is unused.
  • Workplane.cboreHole(diameter, cboreDiameter, cboreDepth, depth=None, clean=True) Counterbore: thru/blind hole then a larger blind cut.
  • Workplane.center(x, y) Shift the workplane origin in the current XY.
  • Workplane.chamfer(length, length2=None) Chamfer currently selected edges. Asymmetric ``length2`` is not implemented.
  • Workplane.circle(radius, forConstruction=False) Pending circle. Construction flag is ignored (not drawn).
  • Workplane.close() Close the open path into a pending wire.
  • Workplane.cut(toCut, clean=True, tol=None) Boolean cut: this solid minus ``toCut`` (Workplane or Solid).
  • Workplane.cutBlind(until, clean=True, both=False, taper=0) Cut pending wires to a depth. ``taper`` is not implemented.
  • Workplane.cutThruAll(clean=True, taper=0) Cut pending wires through the part AABB. ``taper`` is not implemented.
  • Workplane.cylinder(height, radius, direct=None, angle=360, centered=True, combine=True, clean=True) Cylinder. ``direct`` is the axis (default workplane Z). Full 360° only.
  • Workplane.each(callback, useLocalCoordinates=False, combine=True, clean=True) Not implemented.
  • Workplane.eachpoint(callback, useLocalCoordinates=False, combine=True, clean=True) Not implemented.
  • Workplane.edges(selector=None) Select registered edges (``|Z``, ``#Z``, named patches).
  • Workplane.extrude(until, combine=True, clean=True, both=False, taper=0) Extrude pending 2D wires. ``taper`` is not implemented.
  • Workplane.faces(selector=None) Select registered faces (``>Z``, ``|Z``, named patches).
  • Workplane.fillet(radius) Fillet currently selected edges.
  • Workplane.hLine(distance) Horizontal relative line.
  • Workplane.hLineTo(x) Horizontal line to absolute X.
  • Workplane.hole(diameter, depth=None, clean=True) Circular hole. ``depth=None`` means thru-all.
  • Workplane.intersect(toIntersect, clean=True, tol=None) Boolean intersection with another Workplane or Solid.
  • Workplane.largestDimension() Diagonal of the Part AABB used when this Workplane created a Part.
  • Workplane.line(xDist, yDist) Relative line from the cursor.
  • Workplane.lineTo(x, y) Line from the cursor to an absolute 2D point.
  • Workplane.loft(ruled=False, combine=True, clean=True) Loft stacked ``workplane()`` sections. ``ruled=True`` uses LOFT_STYLE_RULED.
  • Workplane.mirror(mirrorPlane='XY', basePointVector=(0, 0, 0), union=False) Not implemented (kernel has no solid transform yet).
  • Workplane.move(xDist, yDist) Relative move of the 2D cursor.
  • Workplane.moveTo(x, y) Set the 2D cursor and start a new open path.
  • Workplane.offset2D(d, kind='arc', forConstruction=False) Not implemented on Workplane; use camber.Sketch.offset instead.
  • Workplane.placeSketch(*sketches) Append wires from ``cqcompat.Sketch`` instances as pending geometry.
  • Workplane.polarArray(radius, startAngle, angle, count, fill=True, rotate=True) Polar array of locations. Angles in degrees. ``rotate`` is unused.
  • Workplane.polygon(nSides, diameter, forConstruction=False) Regular polygon inscribed in a circle of ``diameter``.
  • Workplane.polyline(listOfXY, includeCurrent=False) Open path through 2D points (does not close).
  • Workplane.pushPoints(pntList) Set 2D locations for the next primitive (rect/circle/box).
  • Workplane.radiusArc(endPoint, radius) Arc from the cursor to ``endPoint`` with signed radius (CCW if positive).
  • Workplane.rarray(xSpacing, ySpacing, xCount, yCount, center=True) Rectangular array of locations in the workplane.
  • Workplane.rect(xLen, yLen, centered=True, forConstruction=False) Pending rectangle. Construction flag is ignored (not drawn).
  • Workplane.revolve(angleDegrees=360, axisStart=None, axisEnd=None, combine=True, clean=True) Revolve pending wires. Default axis is workplane X through the origin.
  • Workplane.rotate(axisStart, axisEnd, angleDegrees) Not implemented (kernel has no solid transform yet).
  • Workplane.shell(thickness) Not implemented (no offset-solid in the kernel yet).
